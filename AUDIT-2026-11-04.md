Enhancements are not all mandatory release blockers.

## Implementation progress — alpha.46

This first implementation batch addresses **14 entries: 1, 2, 3, 5, 6, 7, 8, 9, 17, 18, 22, 27, 37 and 39**. The original findings remain below as review history; these entries are no longer counted as untouched code gaps. **36 entries remain open**, including all 17 live-verification items.

- Standard controls explicitly show unavailable; saved Standard preferences migrate to Native. This resolves misleading selection, not the missing embedded Standard capability.
- Resolver cancellation/auth/network failures no longer retry best indiscriminately. Only Streamlink's missing-rendition error triggers quality fallback; generic resolution failures no longer invent offline status.
- Playback/quality caches include a digest of the appropriate service session. Kick quality discovery uses Kick cookies, and Twitch credentials are not passed to Kick launches. Hover prewarming uses the channel preference/default 720p.
- Runtime availability is rechecked after 30 seconds. Layout lock persists, interrupted drags clear, panel/layout write failures stay usable with warnings, and no-window polling stops.
- OBS disconnect errors are handled. Initial Kick lookup failures and missing room IDs retry with capped backoff; leaving/switching channels cancels or ignores stale work.
- Regression checks cover cancellation, rendition fallback, session changes, prewarming, Kick startup retry/cancellation and desktop control/lock behavior. Prolonged real playback, performance, OBS audio and platform-specific checks remain open.
